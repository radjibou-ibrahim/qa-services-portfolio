# E-commerce Testing — SauceDemo QA Case Study

## Overview

This case study presents a personal manual QA testing project performed on the SauceDemo e-commerce application.

The objective was to demonstrate a structured approach to testing an e-commerce workflow from authentication to order completion.

> This is a personal QA project created to demonstrate practical testing skills. It is not a professional client project.

---

## Application

**Application:** SauceDemo  
**Type:** E-commerce Web Application

The project focused on the main shopping and checkout workflows.

---

The testing covered:

---

## Test Execution Results

A total of **35 test cases** were executed.

| Result | Count |
|---|---:|
| PASS | 32 |
| FAIL | 3 |
| BLOCKED | 0 |
| Pass Rate | 91.43% |

Three functional test cases failed during execution.

The identified issues included:

- Missing product description on the Product Details page
- Missing order confirmation page/message after completing an order
- Missing confirmation state after completing the full purchase flow

Additional exploratory testing identified other anomalies that were documented separately in the complete project.
