# Banking Application — QA Case Study

## Overview

This personal QA case study demonstrates manual testing activities performed on a demo banking application.

The objective was to validate key customer and bank manager workflows and demonstrate a structured software testing approach.

> This is a personal QA demonstration project. It is not affiliated with or commissioned by the application owner.

---

## Application

**Application:** XYZ Bank — Demo Banking Application

**Application Type:** Web Application

**Testing Type:** Manual QA Testing

---

## Scope

The testing covered the following functional areas:

- Customer Authentication
- Bank Manager Authentication
- Customer Dashboard
- Account Information
- Account Balance
- Transaction History
- Deposit
- Withdrawal
- Customer and Account Management
- Logout and Navigation

---

## Testing Activities

The project included:

- Requirements analysis
- Test planning
- Test scenario design
- Test case design
- Test data preparation
- Functional testing
- Positive and negative testing
- Exploratory testing
- Boundary Value Analysis
- Equivalence Partitioning
- Test execution
- Defect identification and reporting
- Retesting and regression testing where applicable
- Test summary
