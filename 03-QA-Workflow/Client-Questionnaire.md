# Client Questionnaire

## Overview

This questionnaire is used to collect the essential information required before starting a QA testing project.

The objective is to understand the product, define the testing scope, identify access requirements and establish the expected deliverables.

Not every question is mandatory for every project. The questionnaire is adapted according to the application and the selected QA service.
